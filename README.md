# Flee-the-Verity

Dude we gotta get outta verity's trap dungeon x flee the facility type crib!!!!!          
Hack the computers to force the facility (verity variant) to shutdown and open the exits      
Or risk being put into a test tube and becoming a variant yourself

## Controls

| | Move | Interact |
|---|---|---|
| Blue (player 1) | W A S D | E |
| Orange (player 2) | Arrow keys | P |

Press **R** to restart.

## Rules

- Press the interact key at a computer to hack it or hold at a test tube to free your teammate
- If Verity catches you, you get locked in the nearest test tube. So don't get caught!!
- Buildings are dark, so use your flashlight to see
- Exits open once every computer is hacked and nobody (variant) is stuck in a tube
